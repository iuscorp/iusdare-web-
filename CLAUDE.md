# Repositorio iusdare-web-

- `index.html`: sitio web de IUS DARE (Revoredo Iuscorp).
- `revoredo-video-studio/`: **Revoredo Abogados Video Studio**, el sistema de producción audiovisual (Remotion). Para cualquier tarea de video, leer `revoredo-video-studio/CLAUDE.md` y seguir su flujo obligatorio: análisis → loop de retención → B-roll → **canvas de preview** → validación → edición → QC.
